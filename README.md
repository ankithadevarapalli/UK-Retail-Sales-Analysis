# UK-Retail-Sales-Analysis
UK retail sales analysis using MySQL to explore sales performance, products, regions, customers and order trends.

## Project Overview
This project analyses UK retail sales data using MySQL to identify key business trends and insights across sales, products, regions, customers and order performance.

## Key Insights
- Total Orders: 1,200
- Total Sales: £77,283.71
- Average Order Value: £64.40
- England generated the highest regional sales.
- Electronics was the highest-performing product category.
- Noise Cancelling Headphones was the top-selling product.
- 90.75% of orders were completed successfully.
